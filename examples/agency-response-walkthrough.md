# Fictional agency-response walkthrough

Use invented records only. Run `seed_demo` with your chosen local password, then complete the [intake walkthrough](intake/README.md) so the North/Studio reported claims exist. Select `demo-july-2026-v1`. Existing signed history is retained; repeat exercises may start from a later case version.

1. Sign in as `demo.agency`, choose **Sample Studio Agency**, and open **Reported claims**. Open `DEMO-NORTH-101` and choose **Prepare objection draft**. Enter a partial disputed amount such as `240.10`, a reason, a fictional explanation and a supporting plain-text statement. Save the private draft. It is visible within the agency; no case is opened yet and a preparer cannot sign.
2. Sign in as `demo.agencyapprover` in the same agency. Open **Objections & evidence**, choose **Agency-private drafts**, and review that draft's exact claim, amount, explanation, source digest and base case version. If it is still current, enter **13 October 2026, 12:00 PKT**, accept the fictional declaration and sign. Actual server time is recorded separately. Verify/download the signed JSON receipt.
3. The fictional ordinary response window is **12 October 2026, 10:00 PKT inclusive through 16 October 2026, 17:00 PKT exclusive**. Signing at the closing instant is rejected. The window comes from [its own source](candidate-response-window.txt), without modifying the sealed complaint calendar. It is not approved policy.
4. From the case, prepare an amended draft using its current version and a later simulation inside the window. An approver signs it as a new revision. Use **Prepare withdrawal** with an explicit reason to preserve the earlier versions. A reopening requires a new draft and a later simulation inside the ordinary window. A withdrawal may be signed after closing; every version remains accessible. Stale drafts require a new draft and review.
5. Sign in as `demo.channel`, choose **Sample North Television**, and inspect the submitted case. The channel sees signed revisions, not private source drafts. Add a fictional **evidence statement** at **20 October 2026, 12:00 PKT**. It is classified as late and remains unverified. The agency can add its own statement. No original file is uploaded and supplied references are not fetched or verified.
6. Review **Reported claims** by channel, client and cycle. The original reported due stays unchanged; the current disputed amount is separate. Accepted credits, verified settlement and remaining reportable balance are unknown. A withdrawn case has no active disputed amount but retains its earlier receipts. No objection, withdrawal or statement pays a claim, clears it or pauses enforcement.
7. Switch to **Sample Orbit Agency** to confirm North/Studio records are absent. `demo.reviewer` can inspect submitted records under PBA oversight without party mutation controls. `demo.policy` prepares candidate policy only and has no objection navigation.

If a response is lost, keep the tab. **Response commands awaiting confirmation** opens the saved source after a reload. Check the protected result first, then explicitly retry the original saved command if no result exists. Recovery retains the same UUID, payload, declaration and simulation time; do not prepare a replacement command to guess whether the first succeeded. Missing recovery storage sends no command. Session storage includes pending statement text, is scoped by user/workspace, and may disappear when the tab closes; server records remain authoritative.

The local walkthrough may already contain completed versions. Do not edit or delete those records to repeat a scenario. Use another clearly fictional reported claim or a valid later version. Production filing/signing, original-document storage, retention, MFA, policy acceptance, settlement and enforcement remain separate release work.
